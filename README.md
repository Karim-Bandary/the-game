# مشروع الحُكم

لعبة محاكاة رئاسة دولة — نص وأرقام، للموبايل.

**الرابط الحي:** https://karim-bandary.github.io/the-game/

كل تعديل بيترفع هنا بيعدي على الفحص الآلي الأول، ولو عدّى بيتنشر على الرابط ده لوحده خلال دقيقتين.

---

## المحتويات

| المجلد | فيه إيه |
|---|---|
| `index.html` | الصفحة الرئيسية — منها توصل لكل حاجة |
| `docs/` | مستندات التصميم والأرقام ومسوّدات الشاشات |
| `data/` | أرقام اللعبة كلها — `balance.json` و `setup.json` |
| `tools/` | المحاكي، ومولّدات المستندات، والفاحص |
| `.github/workflows/` | مسار البناء الآلي |

## قواعد المشروع

**١. الأرقام في `data/` مش في الكود.** أي رقم في اللعبة موجود في ملف JSON. تغيير التوازن = تعديل ملف بيانات، مش برمجة.

**٢. المستندات دي بتتولّد، ما بتتكتبش.** `docs/balance.html` و `docs/app-mockup.html` و `docs/setup-mockup.html` كلهم بيتعملوا من `data/` عن طريق `tools/`. لو عدّلت واحد فيهم بالإيد، الفحص هيقف البناء — عشان المستند واللعبة ما يقولوش كلام مختلف أبدًا.

**٣. أي باج بيظهر مرة، بيتحول لفحص دايم.** `tools/check.py` بيتشغل مع كل رفع وبيوقّف البناء لو حاجة غلط. و`tools/test_check.py` بيكسر حاجات بالعمد عشان يتأكد إن الفاحص نفسه شغال.

## تشغيل الأدوات محليًا

```bash
python3 tools/check.py              # الفحص الكامل
python3 tools/test_check.py         # فحص الفاحص
python3 tools/sim.py                # المحاكي — بيلعب اللعبة ويطبع النتايج
python3 tools/build_balance_doc.py  # يعيد توليد مستند الأرقام
python3 tools/build_mockup.py       # يعيد توليد شاشات التطبيق
python3 tools/build_setup_mockup.py # يعيد توليد شاشات البداية
```
